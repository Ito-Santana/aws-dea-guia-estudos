# AWS DEA-C01

Este site reúne meu guia de estudos para a certificação `AWS Certified Data Engineer - Associate (DEA-C01)`.

A proposta aqui é simples: transformar estudo técnico em documentação organizada, útil para revisão de prova e boa o suficiente para consultar depois sem parecer um monte de anotação solta.

## Sobre este projeto

Este material foi feito por mim, **Ítalo Santana**, para consolidar meus estudos em engenharia de dados na AWS.

Sou **AWS Certified** e **Databricks Certified**, e este espaço funciona como meu repositório de estudo, revisão e organização de conhecimento técnico.

- LinkedIn: [Ítalo Santana](https://www.linkedin.com/in/italo-santana-26bb94255/)
- GitHub: [Ito-Santana/aws-dea-guia-estudos](https://github.com/Ito-Santana/aws-dea-guia-estudos)

## Ideia do guia

Em vez de deixar o estudo espalhado em PDF, rascunho e anotação isolada, a ideia foi montar uma base mais clara para:

- revisar conceitos importantes da DEA-C01;
- organizar o conteúdo por trilha;
- conectar teoria com cenários reais de engenharia de dados;
- manter o material vivo e versionado.

## O que é esta página

Esta é a página inicial do site.

Ela funciona como visão geral do material inteiro. Os links detalhados de cada trilha ficam nas páginas índice de cada seção.

## Como usar este site

- use a navegação lateral para entrar por pasta e assunto;
- comece por `Fundamentos de Engenharia de Dados` se quiser fechar base conceitual;
- avance para `Armazenamento` e depois para os blocos que você adicionar;
- abra o repositório no GitHub pelo link no topo ou na barra lateral.
